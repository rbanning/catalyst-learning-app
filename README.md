# Catalyst Learning

_Accelerate your strategic thinking with interactive scenarios_

## Hallpass Academy Series App

This NextJS web app was developed as part of [Hallpass Academy's](https://academy.hallpassandfriends.com) App Series where we walk through the steps of creating an web-based solution, highlighting various aspects of the process that we found interesting.

This application is offered free for use, both personal and commercial.  All we ask is that you include the "created by" attributions that appear in the metadata and footer.

## Following Along in Development

If you want to follow along with the app's development, you can do so in a variety of ways.

### Notes Folder

We break our progress into a number of steps, and for each, we jot down 
some notes which we place in the `./notes/` folder.  Sometimes, there
will be multiple notes added for a step. Other times, the note is brief.

### Branches

Each step is developed in a separate branch, so you can see the app 
develop.  The `main` branch has the full app, and the `publish` branch
is reserved for our hosted version of the app. [catalyst-learning.hallpassandfriends.com](https://catalyst-learning.hallpassandfriends.com)
